# Coffee Sales Dashboard (Excel)

An interactive Excel dashboard for exploring coffee-sales performance, built in a single workbook.

## What it does

- Cleans and enriches raw order data with lookup formulas (XLOOKUP and INDEX/MATCH).
- Shapes the data with Power Query.
- Summarises sales with PivotTables and PivotCharts.
- Lets you filter the dashboard interactively with slicers and a timeline.

## Built with

- Microsoft Excel
- Power Query
- PivotTables and PivotCharts
- Slicers and timelines

## Workflow

1. Prepare and clean source data.
2. Use lookup formulas such as XLOOKUP and INDEX/MATCH to enrich records.
3. Transform data with Power Query.
4. Build PivotTables and PivotCharts.
5. Add slicers and a timeline for interactive filtering.
6. Arrange the dashboard to make key trends easier to explore.

## Open it

1. Download `coffeeOrdersData (dashboard).xlsx` from this repository.
2. Open it in a recent desktop version of Microsoft Excel (XLOOKUP needs Excel 2021 or Microsoft 365).
3. Go to the dashboard sheet and use the slicers and timeline to filter.
